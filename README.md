# 申请人考试复习小程序

1. 打开微信开发者工具，选择「小程序」和「导入项目」。
2. 选择本目录，也就是包含 `project.config.json` 的目录。若工具要求选择 AppID，可先选「测试号」体验。
3. 点击「编译」，从模拟器首页开始练习。

题库内置 380 道题，分为 19 课，保留原文的章节编号。支持按课练习、随机抽取 10 题和错题重练。每道题提交后显示正确答案。答题进度和错题保存在本机。

需要重新生成题库时，使用 Python 3.10 或更新版本运行以下命令。小程序运行时直接读取已经生成的题库。

```powershell
python tools/import_questions.py "./选择题题库.docx"
```
